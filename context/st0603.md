# Scope

The *value* standard behind every absolute timestamp in the bundle. It defines
the time system and its representations; other standards say where to put them.
[0601](./st0601.md) item 2, [0903](./st0903.md) timestamps and
[0604](./st0604.md)'s SEI payloads are all "a Precision Time Stamp as defined in
ST 0603" — so this doc is the source for what those bytes *mean*, and 0604 is
the source for how they are framed in the video ES.

# MISP Time System (§6)

- **Epoch:** `1970-01-01T00:00:00.0Z`.
- Derived from UTC **without leap seconds** — a continuous count, not UTC.
- Offset relationships: MISP Time = TAI − 8.000082 s; GPS Time = TAI − 19 s. UTC
  is recoverable from MISP time given the correct offset and leap seconds.

# Representations (§7)

| | Resolution | Encoding |
|---|---|---|
| **Precision Time Stamp** | microseconds | 64-bit unsigned, µs since the epoch |
| **Nano Precision Time Stamp** | nanoseconds | 64-bit unsigned; `Nano = 1000 × Precision` (§7.3) |
| **Commercial Time Stamp** | one video frame | SMPTE ST 12-1 time code, `HH.MM.SS.FF` (§7.5) |

Precision → Nano → Precision round-trips losslessly; Nano → Precision → Nano
does not. The Commercial Time Stamp is cyclical, so its values are not unique
over time, and editing tools may rewrite it.

Requirements: the Precision Time Stamp **shall** be a 64-bit unsigned integer of
"microseconds since 1970", derived from UTC without leap seconds (§8 list).

# Time Status byte (§7.4, Table 3)

One byte, UL `06.0E.2B.34.01.01.01.01.0E.01.01.03.10.00.00.00`. Carried
alongside a Precision or Nano Precision Time Stamp — this is the byte
[0604](./st0604.md) §7.3 defers here for, at byte 17 of its 28-byte SEI payload.

| Bits | 0 | 1 |
|---|---|---|
| bit 7 | **Locked** — internal clock locked to an absolute time reference | **Lock Unknown** — not locked |
| bit 6 | **Normal** — time incrementing forward linearly | **Discontinuity** — it is not |
| bit 5 | **Forward** — jumped forward (meaningful when bit 6 = 1) | **Reverse** — jumped backwards |
| bits 4-0 | Reserved, `11111` | — |

So `0x1F` = Locked / Normal / Forward with the reserved bits set, and `0x9F` is
the same with bit 7 flipped to Lock Unknown. Bit 5 only carries meaning when
bit 6 signals a discontinuity.

Note what bit 7 does *not* say: it is about an internal clock's lock to a
reference, not about GPS specifically. GPS appears in §6 only as one way to
obtain the offsets.

# Why it matters here

- It is the normative source for claims the bundle previously carried
  secondhand — "uint64 µs since 1970, no leap seconds" in
  [0601](./st0601.md), [0903](./st0903.md) and [0107](./st0107.md).
- The Time Status byte we emit in ST 0604 SEI generation
  ([ADR 0023](./decisions/0023-st0604-sei-passthrough.md)) is defined only
  here; Table 3 is what makes that byte checkable rather than assumed.
- The remaining deferred 0604 scope
  ([ADR 0009](./decisions/0009-st0604-deferred.md)) needs it: decoding Time
  Status on read, and the Commercial Time Stamp, are both defined here.
