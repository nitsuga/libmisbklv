# Scope

Maps a float in a specified `[min, max]` range to a non-negative integer of `L`
bytes, and back, within a specified precision. Saves bandwidth vs IEEE floats
(fewer bytes for the same usable precision). Two starting points: **IMAPA**
(specify precision → compute length) and **IMAPB** (specify length → compute
scaling factors). Reverse mapping is **RIMAPB** (RIMAPA is unnecessary — length
is known from the byte count).

# Mapping

Forward (float `x` → int `y`), §7.2.1:

1. If `x` is a special value → table lookup (§7.2.3).
2. If `x < a` → `IMAP_BELOW_MINIMUM`.
3. If `x > b` → `IMAP_ABOVE_MAXIMUM`.
4. Else `y = truncate(sF * (x - a) + Zoffset)`; take the lower `L` bytes.
   `sF` = forward scaling factor, a power of 2 (may be implemented as a shift).

Reverse (int `y` → float `x`), §7.2.2:

1. `special = Bit(msb, y) & Bit(msb-1, y)`; if set → table lookup.
2. Else `x = sR * (y - Zoffset) + a`. `sR` = reverse scaling factor.

**Zero-offset:** `0.0` maps to a specific integer; negatives map below it,
positives at/above it. Negative zero maps to positive zero (1201.1-12).

# Special values

The top two msbs distinguish normal from special (Table 1). When msb and
msb-1 are both 1, the next bits select an IEEE-754-style value (±∞, ±QNaN,
±SNaN), a MISB-defined value, or a user-defined value (Table 2). MISB-defined
(Table 3): `IMAP_BELOW_MINIMUM`, `IMAP_ABOVE_MAXIMUM`, plus RESERVED and
RESERVED-GROWTH rows. Default decode: below-min → min, above-max → max. For
forward-compat, handle unknown special values without crashing. §7.2.3.

# Notation

`IMAPA(<min>, <max>[, <precision>])`; `IMAPB(<min>, <max>[, <length bytes>])`;
`RIMAPB(<min>, <max>)`. User-defined bit patterns are listed immediately after
the notation. §7.3.
