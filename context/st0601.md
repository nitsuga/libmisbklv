# Scope

UAS Datalink Local Set — a bandwidth-efficient SMPTE 336 KLV Local Set of
platform / sensor / frame / target metadata, ~143 items (ST 0601.19). Travels
in an MPEG-2 Transport Stream alongside compressed Motion Imagery over the
datalink. Items are TLV triplets; the Tag is local to the set (not a Universal
Key).

# Structure

Packet = 16-byte Universal Label (Key) + BER-encoded Length-of-Value + Value
(the TLV items). §6.3.

- **UL Key:** `06.0E.2B.34.02.0B.01.01.0E.01.03.01.01.00.00.00` (CRC 56773),
  registered in ST 0807. §6.2. Historical UL keys forbidden (0601.8-19).
- **Mandatory items:** Item 2 Precision Time Stamp (uint64, 8 B, µs since
  1970-01-01T00:00:00Z) — must be first; Item 65 UAS Datalink LS Version
  Number; Item 1 Checksum (uint16) — must be last. §6.4, §6.6.
- Item order otherwise arbitrary (unless an SDCC-FLP dictates); some items are
  multi-use. §6.3.
- All items expressed per [ST 0107](/st0107.md) (0601.8-03).

# Encoding

Tag / length / value per [0107](/st0107.md). Numeric items are a mix: raw
big-endian integers (uint8/16/32, int8/16/32, …) and **IMAPB-mapped floats**
(latitude, longitude, several angles) per [ST 1201](/st1201.md), each with
per-item special values. Strings are UTF-8. Per-item decode detail lives in
§7; the item table (Table 1) lists tag, name, units, format, length, SDCC,
multi-use — see [`ST0601.19.txt`](../references/ST0601.19.txt) around line 658
for the full table.

# Special values (§7.5)

- **Out of Range** (below min / above max) for mapped-integer items (e.g.
  pitch, roll) — 0601.13-27.
- **N/A (Off-Earth)** for lat/lon when the sensor isn't pointing at earth
  (e.g. self-inspection) — 0601.13-28.
- **Reserved** for backward compatibility.

Receivers must check before using a value.

# Packs (§6.3.2)

- **Variable Length Pack (VLP):** length-value pairs, tag suppressed; a
  zero-length pair preserves order for an unknown/omitted value.
- **Defined Length Pack (DLP):** values only, predefined lengths; no unknowns.
- **Floating Length Pack (FLP):** DLP whose final item is variable-length.
- Truncation packs: VLP/DLP with trailing items removed; total length must
  reflect the truncation.

# Nesting (§6.3.3)

Another Local Set may be the Value of an item (e.g. Item 73 = RVT LS). Nested
items are **scoped** — Item 8 inside the RVT LS is not Item 8 of the UAS
Datalink LS. The nested LS's value excludes its own key, length, and checksum.
[ST 0903](/st0903.md) (VMTI) nests here; so do ST 0102 (security) and
ST 0806 (RVT).

# Report-on-Change (§6.5)

0601 declares RoC. Items are Known-Changing / Known-Static / Unknown; ZLI =
immediately Unknown; 30 s refresh; metadata and list distribution spread
items over time.

# Segment / Amend (§7.6)

Item 100 Segment LS and Item 101 Amend LS (both multi-use), plus Item 143
Metadata Substream ID (MSID) — a truncation pack holding a serial number or
UUID. Amend/Segment hierarchies are recursive (substreams within substreams);
each child carries its parent MSID lineage. 0601.19-41..44. Added in 0601.19.

# Relationships

Profile of [0107](/st0107.md); numeric items use [1201](/st1201.md);
timestamps use ST 0603. Nests [0903](/st0903.md), ST 0102, ST 0806, …
Complementary (not nested) to [0604](/st0604.md), which carries timestamps in
the video elementary stream rather than the KLV stream.
