# Scope

Inserts Absolute-Time timestamps into the *compressed video elementary
stream* — not the KLV metadata stream. Applies to H.262/MPEG-2, H.264/AVC,
H.265/HEVC. Defines the Precision Time Stamp (µs), the Nano Precision Time
Stamp (ns, H.265 only), and the Commercial Time Stamp (HH:MM:SS:FF). All based
on ST 0603.

# Precision Time Stamp structure (§7)

28 bytes total:

1. **Identifier (16 B):** ASCII `MISPmicrosectime` for H.262/H.264; UUID
   `a8687dd4-d759-3758-a5ce-f0338b6545f1` for H.265.
2. **Time Status (1 B):** reference-source info per ST 0603.
3. **Modified Precision Time Stamp (11 B):** the 8-byte uint64 µs value with
   `0xFF` Start-Code-Emulation-Prevention bytes inserted between successive
   2-byte pairs (pairs at bytes 18-19, 21-22, 24-25, 27-28; `0xFF` at 20, 23,
   26). §7.4, Table 2.

# Nano Precision Time Stamp (§8)

H.265 only. Identifier UUID `cf848278-ee23-306c-9265-e8fef22fb8b8`; same
1-byte status + 11-byte modified form (8-byte ns value with `0xFF` stuffing).
Table 3.

# Insertion points

- **H.262/MPEG-2:** `user_data` field between picture header and picture data.
  0604.5-18/19.
- **H.264/AVC:** `user_data_unregistered` SEI — `uuid_iso_iec_11578` = the
  16-B identifier, `user_data_payload_byte` = the 12-B status + modified
  timestamp. 0604.4-10/12.
- **H.265/HEVC:** `user_data_unregistered` SEI, identifier per §7.2
  (Precision) or §8.1 (Nano). 0604.6-22/23, -24/-25.

# Commercial Time Stamp (§9)

HH:MM:SS:FF time code. MPEG-2: `time_code` field in the GOP header (25-bit).
H.264: `pic_timing` SEI (hours 5b, minutes 6b, seconds 6b, n_frames 9b + flags).
H.265: `time_code` SEI. 0604.3-09/11, 0604.4-15.

# Emulation prevention

The `0xFF` stuffing bytes keep timestamp data from being misread as H.26x
start codes — the same concept as H.264's `emulation_prevention_byte`. On
insert, stuff; on extract, de-stuff (drop the `0xFF` separators, reassemble the
8-byte value).

# Relationships

A separate layer from the KLV metadata stream ([0601](/st0601.md) /
[0903](/st0903.md)): 0604 lives in the video ES via SEI / `user_data`; the KLV
stream is a separate PID in the MPEG-TS. Both rely on ST 0603 for time
semantics. Applying 0604 needs access to NAL units / SEI — directly relevant
to the gstreamer/ffmpeg integration.
