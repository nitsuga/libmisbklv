# Scope

Baseline requirements for all KLV in Motion Imagery. The keystone: it
restates the KLV mechanics that the paywalled SMPTE ST 336 defines, so an
implementation can conform to MISB KLV without owning 336. MISB standards are
a profile of SMPTE 336.

# Core rules

- **Bit/byte order: big-endian** (msb / MSB first). 0107.2-01/02.
- **Local Set** = a block containing a list of TLV triplets (Tag-Length-Value).
  The Tag is local to the set (not a Universal Key); Length = byte count of
  Value; Value = the bytes. Decoders **skip unknown items** by reading Length
  and advancing — this makes a decoder future-proof. 0107.3-03/04.
- **Tag encoding: BER-OID** (ASN.1). Chain of bytes; msb=0 terminates the chain.
  First byte 0x00–0x7F → one-byte tag. `0x80` is forbidden as a first byte
  (no leading zeros). §6.3.1.
- **Length encoding: BER short or long form, fewest bytes.** Short form:
  one byte 0x00–0x7F. Long form: `0x8N` (N = count-of-count bytes) followed by
  the count. 0107.3-05, §6.3.2.
- **Value encoding: fewest bytes** per type (§6.3.3.1):
  - `float`/`float16`/`float32`/`float64` → IEEE 754 binary16/32/64.
  - `IMAPA`/`IMAPB` → [ST 1201](./st1201.md) float→int mapping.
  - `int`/`uint*` → big-endian; variable-length variants drop leading zero /
    sign-extension bytes.
  - `ber-oid`, `ber` → ASN.1 BER rules.
- **Strings** (§6.3.3.2): UTF-8 per ISO/IEC 10646. Empty string = single
  `0x00` (length 1). **Length 0 = "Unknown"** (distinct from empty string).
  Strip control chars (0x00–0x08, 0x0B–0x0C, 0x0E–0x1F, 0x7F) and
  leading/trailing whitespace unless the item allows them. 0107.3-12/13.

# Report-on-Change

Bandwidth technique a standard may declare. Items are sent at their Minimum
Refresh Period or when they change; item states are Known-Changing /
Known-Static / Unknown. Default Metadata Refresh Period = 30 s; an item not
updated within it becomes Unknown. **Zero-Length Item (ZLI)** = tag + length 0
= value immediately Unknown; valid only for single-use items; discouraged for
child Local Sets / Packs. 0107.4-14..19, §6.3.4.

# Metadata distribution

Spread Known-Static items across the 30 s window (e.g. item A at t=0, B at
t=5, C at t=10) to avoid bandwidth spikes; list items may be split across
packets. §6.3.5.

# Conformance (hard requirements)

2-01/02 (big-endian), 3-03 (SMPTE 336 compliance), 3-04 (skip unknown),
3-05 (fewest-bytes length), 3-06/07 (value-length limits), 3-08..13
(type-specific encoding incl. 5-20 for float sizes), 4-14..19 (RoC/ZLI).

# Relationships

Foundational; every other MISB Local Set — [0601](./st0601.md),
[0903](./st0903.md) — is a profile of this. Numeric items delegate to
[ST 1201](./st1201.md); timestamps delegate to ST 0603. ES-layer timestamps
([0604](./st0604.md)) are a separate concern (compression layer, not KLV).
