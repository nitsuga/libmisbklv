# Scope

VMTI metadata for moving/static objects in Motion Imagery (bounding boxes,
contours, tracks, ontology labels). A KLV Local Set; usable standalone or
nested under [ST 0601](./st0601.md). Extends SMPTE KLV per [ST 0107](./st0107.md).
0903.6 is conditionally backward compatible (App. C).

# Processing model (§7)

A list of targets, each with a lifecycle (creation → drop) and four attribute
groups:

- **Administrative** (§7.1.1): target id, detection status, priority,
  confidence, history, algorithm.
- **Image** (§7.1.2): pixel contour, pixel bounding box, centroid, %
  target pixels, color, intensity, image chip, image mask, features, object
  label.
- **Geospatial** (§7.1.3): location (lat/lon/HAE), geospatial bounding box,
  geospatial contour.
- **Tracking** (§7.1.4): track id, detection status, observation time, track
  points list, bounding area, confidence, count, velocity/accel, algorithm.

Lifecycle states (renamed in 0903.6): Active-Moving, Active-Stopped,
Active-Coasting. §7.2.

# Encoding (§9)

- Per [ST 0107](./st0107.md) (0903.4-01); tag/length/value rules as [0601](./st0601.md).
- **VMTI LS** uses byte 6 = `0x2B` (BER-OID tags + BER short/long length →
  unlimited items, no size limit). **Embedded LSs** (VMask, VObject, …) use
  byte 6 = `0x03` (1-byte UINT tags, max 255 items). §9.2.
- Items used **only once** per LS instance (0903.5-98) — no repetition, unlike
  the general LS definition.
- Floats use IMAP per [ST 1201](./st1201.md) (0903.4-03); out-of-range →
  `IMAP_BELOW_MINIMUM` / `IMAP_ABOVE_MAXIMUM`; "Invalid" = IMAP user-defined
  `0xC1`, zero-padded to the required pack length. §9.1.1.
- **Array** (homogeneous simple types as a VLP) and **Series** (homogeneous
  structured elements as a VLP) complex types. §9.1.2/9.1.3.
- Timestamps use ST 0603 Precision Time Stamp (uint64 µs since 1970). §9.2.2.
- **Target coordinates** (§9.2.3): pixel (row-major pixel number, or row/col
  pair) and geospatial. `pixel number = Column + (Row-1) × frame width`,
  1-indexed from top-left.

# 0903.6 changes (§3)

Removed VTrack LS; broad deprecations; added reqs -116..-143; renamed
boundary→boundingBox, boundarySeries→geospatialContourSeries; target states
Active→Active-Moving, Stopped→Active-Stopped, +Active-Coasting; URIs→IRIs;
"Tag"→"Item" terminology.

# Relationships

Nested under [0601](./st0601.md) as a sub-Local Set value, or standalone.
Profile of [0107](./st0107.md); floats via [1201](./st1201.md); timestamps via
ST 0603. Boundaries/contours may reference photogrammetry (ST 0801).
