# Context

The repository historically distributed five MPEG-TS/video files in `data/` and
several extracted `.klv` fixtures derived from them. The files were useful for
backend validation, but their public hosting locations did not establish a
license permitting redistribution. The repository's Apache-2.0 license covers
libmisbklv's source and project-authored test material, not third-party media.

The backend still needs deterministic coverage for ST 0601 encoding, MPEG-TS
framing, both KLV signaling forms (`0x06` and `0x15`), timestamps, malformed and
noncanonical inputs, and video-passthrough integration. Tests that require a
developer's downloaded video are not hermetic.

# Decision

Remove the external media and their derived distributed fixtures from the
current tree. Keep `data/` as an ignored workspace for developer-provided media,
with guidance in [`data/README.md`](../../data/README.md). Replace regression
inputs with deterministic, project-authored fixtures generated by
[`test/fixtures/generate_synthetic_fixtures.py`](../../test/fixtures/generate_synthetic_fixtures.py).
The generator and generated fixtures are distributed under Apache-2.0 and use
only invented values and the Python 3.11+ standard library (`tomllib`).

Coverage that previously depended on the external corpus is represented by
small fixtures for ordinary and extended ST 0601 values, special values,
variable widths, multi-byte BER-OID tags, timed and untimed `0x06` PES, and
`0x15` metadata access units. Media-specific tests use project-owned synthetic
carriers or remain scoped to KLV transport behavior; no test downloads or
requires files from `data/`.

# Alternatives considered

- **Keep the public samples and document their URLs.** Rejected: hosting and
  provenance do not grant redistribution rights.
- **Require developers or CI to download the samples.** Rejected: this leaves
  licensing and network availability outside the project's control and makes
  tests non-hermetic.
- **Remove all media coverage.** Rejected: the backend's transport and timing
  behavior still needs regression protection.
- **Rewrite all repository history immediately.** Deferred: current-tree removal
  is the scoped change. Purging old Git/LFS objects and releases is a separate
  repository-administration operation if full historical withdrawal is required.

# Consequences

- A normal checkout builds and runs the test suite without Git LFS media or
  network access.
- `data/` remains useful for local experiments but cannot accidentally add
  developer-owned media to a commit.
- Synthetic fixtures are smaller, reproducible, reviewable, and explicit about
  their Apache-2.0 provenance.
- Historical probe results in ADRs and `context/backend-scope.md` remain valid
  as historical observations, but they no longer describe shipped test assets.
- Removing files from the current tree does not remove them from old commits,
  tags, release archives, or already-downloaded LFS objects.

# Assumptions / open questions

- The current synthetic transport cases are sufficient for the backend contracts
  they exercise; a future real-world sample may be added only with explicit
  redistribution terms.
- Optional local integration experiments may use developer-provided media, but
  those files are not part of the supported hermetic test suite.
